# Mobile Phone Charging Stand
It's a Mobile Phone Charging stand!

## Features
- Weighs around 51 grams
- Has space for clear double tape at the back to mount it

## Design & Specifications
| Property | Value |
|---|---|
| Designed using | Onshape |
| Printer | Bambu Lab A1 Mini |
| Material | PLA |
| Layer Height | 0.2 mm |
| Supports | Not Required |
| Model Dimensions | 100 × 40 × 80 mm |
| Estimated Print Time | 1 hours 38 minutes |
| Filament Usage | 47.56 g|
